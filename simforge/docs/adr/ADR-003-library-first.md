# ADR-003: Biblioteca de componentes antes que generación de código
**Decisión:** los componentes son especializaciones declarativas de 4 comportamientos probados. La IA selecciona y configura; no genera código de simulación.
**Consecuencias:** % de reutilización medible (`reuse_ratio`); lógica nueva = nuevo comportamiento o regla aislada con tests.
