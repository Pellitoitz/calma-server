## Qué es esta versión

Es la **primera Release Candidate de SimForge 1.0**: un workbench local de simulación DES industrial que lleva un
estudio por estos pasos:

**proyecto → modelo → verificación → aprobación → run → experimento → evaluación económica → comparación → informe /
exportación**

RC1 **no introduce capacidades nuevas** respecto al alcance congelado (`1.0_feature_freeze.md`). Su objetivo es la
estabilidad, la reproducibilidad, la instalación, la persistencia, la trazabilidad y la documentación.

Abre un **periodo de estabilización** (`1.0_stabilization_policy.md`) en el que no se aceptan funcionalidades nuevas.

## Validación industrial: dimensión independiente de la madurez del software

- Todas las capacidades industriales siguen **SYNTHETICALLY_VALIDATED**: probadas con casos de resultado conocido.
- **Ninguna** capacidad se declara REAL_DATA_VALIDATED.
- Economics con datos reales: **NOT_EXECUTED**. Existe un protocolo **READY_FOR_REAL_ECONOMIC_VALIDATION**
  (`docs/validation/economic_real_data_validation.md`), pendiente de recibir datos reales de planta.
- La madurez del software (esta RC) **no** implica validación industrial. La validación de un modelo concreto contra su
  planta es responsabilidad del ingeniero.

## Instalación

```bash
python3.11 -m venv .venv && source .venv/bin/activate
pip install ".[ui,data]"
python -c "import simforge; print(simforge.__version__, simforge.ENGINE_VERSION)"   # 1.0.0rc1 0.9.0
```
