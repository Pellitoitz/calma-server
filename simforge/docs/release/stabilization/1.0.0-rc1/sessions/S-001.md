### Regla black-box

- **Permitido:** `docs/user/01_getting_started.md`, la UI, la CLI y los documentos a los que Getting Started dirige
  explícitamente.
- **No permitido:** código fuente, tests, implementación interna, conocimiento previo de clases o módulos, ni consultar
  al desarrollador para saltarse un problema.
- Si hay que mirar el código para continuar: `DOCUMENTATION_OR_UX_ESCAPE = YES`. Se puede desbloquear, pero se registra
  (y se cuenta en `NUMBER_OF_ESCAPES`).
- Cada hallazgo se clasifica (BUG / UX_FRICTION / DOCUMENTATION_GAP / EXPECTED_LIMITATION / USER_ERROR /
  VALIDATION_GAP / FEATURE_REQUEST / UNKNOWN) y se anota en `../ISSUES.md` **antes** de la siguiente sesión.
- Un BUG no se corrige durante la sesión: primero se registra.
- Una FEATURE_REQUEST se registra como POST_1_0_CANDIDATE.
- RC2_REQUIRED se decide según `../../../1.0_stabilization_policy.md` §3, sin crear la RC2.
