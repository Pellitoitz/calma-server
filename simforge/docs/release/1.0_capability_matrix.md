# SimForge 1.0 — Capability matrix

Dos madureces, nunca mezcladas:

- **Madurez del software (`release_status`).**
  - `IN_1_0`: soportado, probado y documentado.
  - `EXPERIMENTAL`: incluido, pero fuera del contrato.
  - `OUT`: no incluido.
- **Madurez de validación industrial (`validation_level`).**
  - `SYNTHETICALLY_VALIDATED`: tests con resultado conocido.
  - `REFERENCE_PENDING`: comparación con un modelo de referencia bloqueada.
  - `REAL_DATA_VALIDATED`: sólo por capacidad, caso y periodo. **Ninguna capacidad lo tiene en 1.0.**

Columnas:

- `CLI` / `UI`: interfaz disponible.
- `persist.`: la configuración o el resultado se guardan en el proyecto.
- `doc`: documento de referencia.
- `ex`: ejemplo.
