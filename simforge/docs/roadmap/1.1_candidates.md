# SimForge 1.1 — Candidatos

Valoración **cualitativa**: LOW / MEDIUM / HIGH, con el motivo. No hay ROI numérico inventado.

- **Riesgo semántico:** posibilidad de alterar el significado de un modelo o de un resultado.
- **Riesgo de regresión:** posibilidad de romper contratos existentes (01–05, golden, hashes).

## Candidatos de extensión de dominio (no en 1.1 sin decisión explícita)

| ID | Nombre | Motivo |
|---|---|---|
| D01 | Transportador acumulativo (`conveyor`) | no existe y es habitual en planta; toca el motor → DOMAIN_EXTENSION_CANDIDATE |
| D02 | Reglas de despacho adicionales | sólo FIFO, prioridad y wip_target; no se observó un bloqueo concreto |

## Posteriores a 1.1 (POST_1_1_CANDIDATE)

| ID | Nombre | Motivo |
|---|---|---|
| P01 | Mejoras de construcción asistida por IA | fase separada; la IA nunca genera Python ni resultados |
| P02 | Análisis asistido por IA sobre hechos estructurados (resultados → hechos → interpretación opcional → ingeniero) | nunca «LLM → verdad de simulación» |
| P03 | Interoperabilidad (import/export desde otras herramientas) | depende del benchmark AnyLogic (BLOCKED) |
| P04 | Optimización o búsqueda automática | excluida por principio |
| P05 | 3D, gemelo digital, MES/ERP, cloud | fuera de alcance |
