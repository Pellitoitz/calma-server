### Preparación (comandos de referencia)

```bash
git -C <repo> checkout develop/simforge-1.1     # commit 71e30ec o posterior; anotarlo
cd simforge
python3.11 -m venv .venv && source .venv/bin/activate
pip install ".[ui,data]"
python -c "import simforge; print(simforge.__version__)"   # esperado: 1.0.0rc1
simforge ui                                                 # o la CLI: simforge --help
```

No hace falta ninguna clave de API: el asistente de IA no forma parte del workflow objetivo de H-001. Si se usa,
anotarlo en `NOTES` (no se pide ni se copia ninguna clave en este fichero).
